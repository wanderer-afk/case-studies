Device Research Lab

Most beginners stop at blinking an LED. I wanted to see how real open-source devices get built and programmed, so I know what the next step is.

Who it's for

A beginner who wants to go from kit lessons to programming real devices, legally and safely.

What I built

A study track with one note per device. Each note uses the same plain sections: what it is, the hardware, how you program it, the open-source code, what you can build, the legal line, and how to defend against it. I also started a code repo with a first detector.

Proof

  • Seven devices are written up: ESP32, Cheap Yellow Display, HackyPi, P4wnP1, Flipper Zero, Proxmark3 and HackRF One.
  • The rule I set: I study how these work, and I only test hardware I own or am allowed to test.
  • Screenshot still to add: the device table.

Where it stands

In progress. Seven devices are done. One device name ("nine box") is still unclear, and I'm waiting for an answer before I write it up.

What I'd change

  • The long-term design goal hasn't been tested with a real build yet.
  • I still need to pick the next device to buy for hands-on practice.
