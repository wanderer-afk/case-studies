Project 1 - a study assistant that says "I don't know"

Most chatbots answer every question, even when they have no basis for the answer. I wanted a study helper that only answers from my own class notes, and refuses when the notes don't cover the question.

Who it's for

A learner who wants to ask questions of their own notes and trust the answer, because every answer points to the note it came from.

What I built

A local assistant with three parts: 1. Search: it splits my notes into small pieces and finds the pieces closest to each question. 2. Answer: a local AI model writes the answer from those pieces only, with numbered citations like [1] [2]. 3. Refuse: if no piece is a close enough match, it says "Not in my notes" and never calls the model.

The notes are cleaned before the assistant reads them. A check blocks any classmate's name, personal detail or private file path from getting in. The model runs on my PC through Ollama, so nothing is sent to the internet.

Proof

  • Tuning set: 7 of 7 questions answered with a source, and 3 of 3 trap questions refused.
  • Held-out set: 10 of 11 answered, and all 3 trap questions refused. This set was run once, on purpose, so the score is honest.
  • Two copies were built from scratch on a new folder to check the setup works for someone else.
  • 63 automated tests pass.
  • Screenshot still to add: a real question with its citations, and a refused trap question.

Where it stands

Working on my PC. It's a bootcamp project, so the course material stays private. A web-page version runs locally and a Colab (a free online notebook) version gives the same answers on the same notes.

What I'd change

  • The one held-out miss needs a closer look, so I know which kind of question the search gets wrong.
  • The refusal line is set by a score I picked. I'd test more questions before trusting that number on new notes.
