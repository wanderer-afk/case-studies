Command Deck

Desk setups are a big hobby. Command Deck is a themed check-in screen for your desktop: it looks cool, and you spend about 10 seconds on it each day.

Who it's for

People who work from home and like sci-fi-looking desks.

What I built

A themed desktop dashboard, starting from my Arasaka Tower dashboard. It runs offline as an installable web app (a PWA, which is a website you can install like an app). Your data can be backed up in an encrypted file, using the same kind of locking that banks use, with 36 tests. The importers that bring in data from other apps have 106 tests. A preview version (v3) is built.

What I found (2026-09-26)

I had four research agents check the market. Here's what they found: - Free dashboards already do the clock, weather and to-dos. Themed looks sell for $3 to $18 one time. - Some sales sites don't allow digital downloads, so I still need to pick where to sell. - The weather source has to be free for commercial use. I have two options, and I still need to check them. - Nothing copyrighted can ship. A scan tool checks for it.

Proof

  • The offline app and the encrypted backup both work, with tests.

Where it stands

Preview built, not sold. I still need to pick where to sell and check the weather source.

What I'd change
