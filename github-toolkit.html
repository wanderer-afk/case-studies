GitHub Toolkit

GitHub has millions of code projects, and some of them are unsafe to run. I wanted a way to check a project before I touch it.

Who it's for

Anyone who wants to use open-source code without running something harmful by accident.

What I built

A set of steps I run with Claude Code: 1. Find a project. 2. Scout it. I read the details without downloading anything. 3. Sweep it. A copy goes into a sandbox, which is a walled-off folder, and a security scan checks it. 4. Review the results and get a plain go or no-go. 5. Approve, then add it, then check it works.

A rule blocks anything in the sandbox from running until it's been swept and I've said yes. A scheduled task runs every morning at 8:00 and puts the top projects into a report.

Proof

  • Installed on the PC on 2026-09-12. The first daily scan ran that day.
  • I trial-ran 76 commands and switched on 10 of them.
  • Screenshot still to add: the daily report.

Where it stands

Built and running. The GitHub login is set up on the PC, so the scripts can use the full GitHub tools.

What I'd change

  • The security scan only reads the code. It doesn't run it. That catches a lot, but not everything.
