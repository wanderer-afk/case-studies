Arduino UNO R3

A keycard that wakes up my computer sounds like a movie prop. It's really a learning project: a small board reads a card, and a program decides whether to let it in.

Who it's for

A self-taught beginner learning to program real devices.

What I built so far

With Claude as my pair-programmer, I set up the free tools that load code onto the board. Then I wrote the first programs, which Arduino calls sketches. - Sketch 01 (blink) is loaded on the board and runs. - Sketch 02 (read a card) is written and compiles. It's waiting for me to wire the reader. - Each lesson is a note, so I keep what I learned. - The big build is the keycard that wakes the PC, planned in stages. Claude never types or stores my password. I set up the auto-login myself.

Proof

  • Screenshot still to add: the serial monitor showing a card's ID.

Where it stands

In progress. The card reader needs soldering, which means joining metal pins with melted solder. I haven't done that before. A soldering iron costs about $15 to $20, and I'll add that to the budget first.

What I'd change

  • The board can't wake a PC that's fully off, so the first version only works from sleep.
  • Soldering is the blocker. Next time I'd buy a sensor that comes already soldered, or learn soldering first.
