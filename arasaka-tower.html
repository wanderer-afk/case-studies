Arasaka Tower

I had too many tools and too many tabs open, and no single screen that told me what to do today. So I built one.

Who it's for

Me, first. It's my daily screen for jobs, goals, bills, cleanup and every coding project. It could be a model for anyone who wants their own control screen later.

What I built

A one-page cyberpunk dashboard with tabs for jobs, goals, quests (step-by-step plans), a review page where a skeptical AI partner checks my plans, and system. I made a style guide and a repeat loop so every change keeps the same look: plan, build, screenshot, critique, fix. I built it with Claude Code and published it as a Claude artifact, which is a hosted page, so the same link stays up to date.

Proof

  • Version 19 is live. Every version is saved, so you can see how it changed.
  • Screenshot still to add: the title screen and one tab.

Where it stands

Active. The page is private on purpose. Some of the art is based on copyrighted characters, so nothing from it goes public until I redraw it.

What I'd change

  • Some art uses copyrighted characters. A public version needs original art from the start.
  • The setup lives in a long list of steps. One setup script would make it easier for someone else to run.
