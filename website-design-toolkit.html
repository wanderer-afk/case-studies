Website Design Toolkit

Good-looking pages usually take a designer and a day. I wanted a loop I can repeat on my own PC, for free, that designs, checks and fixes a page.

Who it's for

A beginner who will build websites and wants a design habit that works every time.

What I built

A five-step loop, all on my PC: 1. Plan the colors, fonts and layout with a design skill (a saved set of instructions for Claude). 2. Build the page. 3. Screenshot it in a local browser. 4. Critique it with a local vision model (qwen2.5vl:7b). Nothing leaves my PC. 5. Fix it and publish again.

Proof

  • I ran the whole loop on my Arasaka Tower dashboard, now version 19.
  • Screenshot still to add: a before and after of one fix from the critique.

Where it stands

The loop works. Local image generation isn't installed yet.

What I'd change

  • Long file paths broke the screenshots. The fix was a short folder. I wrote the rule into my notes so it doesn't happen again.
  • The image tool needs an admin install, and I haven't done it yet.
